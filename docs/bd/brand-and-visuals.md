# Field-kit visual rules

These rules apply to outward diagrams, meeting handouts and worked-example slides in this directory.
They follow the Wildcat brand guide supplied for this work and the current `wildcat-tranching` BD kit.

## Start with the page

- Use a 16:9 canvas at 1920 x 1080 for screen material.
- Keep the page white or very pale unless it is a cover or section break.
- Use generous margins, one clear heading and no more than five main facts on a page.
- Put figures in pale rounded cards with thin rules.
- Use gradients for a hero band or one focal block, not as wallpaper behind numbers.

## Type

- Headings: Liberation Sans Bold.
- Body and labels: Inter. Use Liberation Sans when Inter is unavailable.
- Reference heading sizes: 60/80, 32/44 and 24/32.
- Reference body sizes: 32/44, 22/36 and 18/32.
- Use sentence case. Keep labels short enough to read on an ordinary laptop screen.

Blue carries performing outcomes. Yellow carries close calls, delay and caution. Red carries loss,
breach and recovery stress. Never use colour as the only distinction between states.

## Illustration

Use sparse black line work, pale cards, ledger shapes, reference-price lines and restrained financial
objects. Generated bitmap art is fine for cover panels and story beats. It must not contain words,
numbers, tickers, addresses, logos or watermarks. Put every label and number in the deck layer or in
Markdown.

## Finance rules

- Show dollars, percentages, fixings and dates as editable text, never generated pixels.
- Label the `12% APR` figure as a test input, not a price.
- Label `1,030,000 USDC` as a collected-proceeds assumption, not an APR calculation.
- Put the barrier breach rule on the same page as the cliff.
- Show borrower full performance before any BTC-linked rebate.
- Show default as a separate branch with zero borrower rebate.
- Keep qualifications on the same page as the claim they limit.

## Delivery check

Every final image should be readable at 1920 x 1080, use the palette above, keep exact facts in the
layout layer and remain legible in a six-image contact sheet. Source renders, prompts and
composition scripts are working files; the outward kit should ship the finished PNGs and editable
text.
